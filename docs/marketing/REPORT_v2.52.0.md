Désormais, les joueurs peuvent voir exactement quand les indices (invalidation de mauvaises réponses) vont se déclencher grâce à des traits colorés sur la barre de progression. Chaque marqueur pulse quand le moment approche, puis s'estompe quand l'indice est révélé.

[BuzzControl v2.52.0] Marqueurs d'indices visuels sur le timer QCM 🎯

Salut à tous !

Je voulais partager la dernière mise à jour de BuzzControl (système de buzzers sans fil pour quiz) : la v2.52.0 apporte une fonctionnalité que plusieurs utilisateurs avaient demandée.

**TL;DR** : Les questions QCM affichent maintenant des marqueurs visuels sur le timer pour anticiper quand les indices (mauvaises réponses invalidées) vont se déclencher.

**Comment ça marche ?**

1. Des traits orange/jaune apparaissent sur la barre de temps
2. Chaque trait indique le moment où un indice sera révélé
3. Animation de pulsation quand le timer approche du seuil (15s avant)
4. Le marqueur s'estompe quand l'indice est déclenché

**Pourquoi c'est cool ?**

Ça ajoute une vraie dimension stratégique au jeu. Les joueurs peuvent choisir de prendre un risque maintenant (4 options) ou d'attendre l'indice (3 ou 2 options). Le suspense est génial à observer en tant qu'animateur.

**Mise à jour**

Si vous utilisez déjà BuzzControl, la mise à jour automatique est dispo depuis la v2.50.0 (menu admin > mises à jour). Sinon, téléchargement classique sur GitHub Releases.
