# Guide des Visuels pour v2.50.0 "Abeille Connectée"

**Date** : 1er février 2026
**Version** : 2.50.0
**Objectif** : Créer des visuels attractifs pour promouvoir la fonctionnalité de mise à jour automatique

---

## 🎨 Identité Visuelle BuzzControl

### Couleurs principales
- **Jaune abeille** : `#FFC107` (primaire)
- **Orange** : `#FF9800` (accent)
- **Gris foncé** : `#333333` (texte)
- **Gris clair** : `#F3F4F6` (fond)
- **Vert succès** : `#4CAF50` (validation)
- **Rouge alerte** : `#F44336` (attention)

### Icônes clés
- 🐝 Abeille (logo BuzzControl)
- ⬆️ Flèche mise à jour
- 🔔 Notification
- 🛡️ Sécurité/Protection
- ⚡ Rapidité
- ✅ Validation

---

## 📸 Screenshots Prioritaires

### 1. Page Updates (`/admin/updates`)
**Fichier** : `screenshot-updates-page.png`

**Ce qu'il faut montrer** :
- Liste des versions avec icônes de statut (✅ actuelle, ⬆️ plus récente)
- Notes de version dépliables
- Bouton "Installer" bien visible
- Interface propre et moderne

**Annotations suggérées** :
- Flèche pointant vers le bouton "Installer" : "Installation en 1 clic"
- Badge sur les icônes : "Statut en un coup d'œil"

**Dimensions recommandées** : 1920x1080 (Full HD)

---

### 2. Badge de Notification
**Fichier** : `screenshot-notification-badge.png`

**Ce qu'il faut montrer** :
- Badge de notification dans la navbar
- Zoom sur le badge vert avec icône 🔔
- Contexte de l'interface admin

**Annotations suggérées** :
- Cercle rouge autour du badge
- Texte : "Notification automatique"

**Dimensions recommandées** : 1200x800

---

### 3. Liste des Versions
**Fichier** : `screenshot-version-list.png`

**Ce qu'il faut montrer** :
- Plusieurs versions listées
- Diversité des statuts (actuelle, récente, obsolète)
- Titres descriptifs ("Abeille Connectée", etc.)

**Annotations suggérées** :
- Légende des icônes de statut

**Dimensions recommandées** : 1200x800

---

### 4. Notes de Version Dépliables
**Fichier** : `screenshot-release-notes.png`

**Ce qu'il faut montrer** :
- Une note de version dépliée
- Rendu Markdown avec emojis
- Sections bien organisées

**Dimensions recommandées** : 1200x900

**Fichier** : `demo-auto-update.gif`

4. Survol de la liste des versions

7. Affichage du dialogue de confirmation
8. Barre de progression de téléchargement

**Dimensions** : 1200x800
**FPS** : 30
**Poids max** : 5 MB

- ScreenToGif (Windows)

Avant publication, vérifier :
- [ ] Qualité d'image : HD minimum (1920x1080)
- [ ] Textes lisibles même en petit format
- [ ] Couleurs conformes à la charte
- [ ] Pas de fautes d'orthographe
- [ ] Liens/QR codes fonctionnels
