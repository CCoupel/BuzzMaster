Maquette — état :
Où : le sélecteur de catégorie (CategoryPicker, inchangé par ailleurs) gagne « ⚙ Gérer… » à côté de « + Créer ». Le dialogue « Gérer les catégories » liste chaque catégorie : pastille de couleur = bouton (cliquer ouvre la palette de 12 teintes + « aucune » ; la couleur s'applique aux badges/chips et à l'éclairage d'ambiance, aperçu 💡), icône = bouton d'envoi (cliquer ouvre le sélecteur de fichier : PNG / JPG / WebP ≤ 2 Mio, carré conseillé ; remplace l'icône ; sur une catégorie intégrée l'image remplace l'emoji, « ↺ emoji » le rétablit), nom (✎ renommage en ligne — nom d'affichage seulement, la clé technique ne change pas), nombre de questions, 🗑 (jamais pour les 8 intégrées 🔒). Suppression d'une catégorie utilisée : garder les questions « sans catégorie » (présélectionné) ou les supprimer aussi ; dans les deux cas les points d'historique de la catégorie sont regroupés dans « Sans catégorie » (historique et palmarès réécrits, sauvegarde automatique) — case de confirmation obligatoire dès qu'un historique existe.
