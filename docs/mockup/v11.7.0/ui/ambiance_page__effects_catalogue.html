Comportement.
• Aperçu : anime les ampoules dessinées, une par groupe configuré (6 dans la maquette ; 6 par défaut si aucun groupe n'existe). Les trames sont calculées par le serveur à partir du fichier de l'effet : l'aperçu montre exactement ce que jouera la salle. Pour un effet de chronomètre, un compte à rebours simulé de 20 secondes s'affiche sous les ampoules. Le bouton devient « ■ Arrêter » ; un seul aperçu tourne à la fois.
• Essayer sur les ampoules : joue l'effet sur les vraies ampoules pendant la durée indiquée, puis l'éclairage revient à son état normal. Le bouton devient « ■ Arrêter l'essai ».
• Étiquettes : « natif » (livré avec BuzzControl), « personnalisé » (fichier de l'utilisateur), « natif modifié » (un fichier de l'utilisateur remplace l'effet d'origine). « utilisé : … » rappelle le ou les moments réglés sur cet effet (global ; les manches ne sont pas listées). Le groupe animateur y figure aussi (« utilisé : groupe animateur »). L'essai sur les ampoules joue toujours sur les groupes de salle, jamais sur le groupe animateur.
• Recharger les fichiers : relit le dossier tout de suite. Sans ce bouton, un fichier modifié est pris en compte en quelques secondes.
• Fichier en erreur : listé dans le bandeau rouge avec le nom du fichier, la ligne et la cause. Si l'effet existait déjà, sa dernière version valide reste jouée.
• Le catalogue n'a pas de bouton de création, de modification ni de suppression : l'éditeur d'effets est prévu pour la version suivante (v11.8.0).

Essai indisponible

Le bouton « Essayer sur les ampoules » est désactivé, avec une infobulle qui donne la raison :

• « L'éclairage d'ambiance est désactivé. »
• « Aucun pont associé » / « Pont injoignable ».
• « L'éclairage est forcé sur ON ou OFF, ou le Flash est actif : repassez en AUTO. »
• « Une question est en cours : l'essai est possible hors question. »

Catalogue vide (dossier illisible) : « Aucun effet disponible » et le bandeau d'erreur ; la pulsation d'origine reste jouée pendant le chronomètre.
