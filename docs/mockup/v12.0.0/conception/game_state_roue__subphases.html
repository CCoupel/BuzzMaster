Conception — version retenue : déroulé d'un tour, horizontal, un couloir par acteur.
Déroulé d'un tour du mode ROUE, de gauche à droite, un couloir par acteur. Les pastilles numérotées sont les 7 étapes du bandeau de l'admin et de l'animateur. Deux moments se passent à voix haute, sans aucun appareil : l'équipe annonce une consonne (entre les étapes 3 et 4) et l'équipe propose une réponse (entre les étapes 5 et 6) ; c'est l'admin ou l'animateur qui les saisit ensuite. Le mode n'ajoute aucune phase au jeu : tout se déroule pendant la phase « en cours » existante.
