Maquette — état :

Éditeur de question (page Quiz). Champ « Pénalité mauvaise réponse », questions QCM seulement, sur la ligne Points / Temps. Saisie de 0 à 100 après un signe « − » fixe, enregistrée en négatif (QCM_WRONG_PENALTY, 0 à −100). 0 = aucune pénalité : c'est la valeur par défaut, pour une nouvelle question comme pour une ancienne question sans le champ (affichée « par défaut ») ; les fichiers ne sont pas réécrits. En jeu : pénalité réglée → un clic sur une mauvaise réponse met −N dans « Points » ; aucune pénalité → ses équipes sont sélectionnées, « Points » passe à 0 et « Appliquer les pénalités (N) » reste désactivé (« Aucune pénalité définie pour cette question »). Distincte des indices progressifs. Inchangé : le reste de l'éditeur (résumé en pointillés) ; les cartes MEMOTION de type QCM n'ont pas ce champ. Révision de la maquette validée : seul le défaut change (0 au lieu de −1).
