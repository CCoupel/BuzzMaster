« LANCER LA PARTIE » quitte la page de jeu et devient une entrée du groupe Préparation de la barre de navigation (#238), à côté de Joueurs, Quiz et Backstage. Il est disponible dans toutes les phases ; le clic ouvre la popup en superposition (maquette admin_new_game__launch_overlay). Deux cas de refus : entracte active (message, la popup ne s'ouvre pas) et popup déjà ouverte sur un autre poste (entrée grisée + bandeau, verrou serveur #253). Le bouton est aussi retiré de la page Backstage ; une seule entrée subsiste.
