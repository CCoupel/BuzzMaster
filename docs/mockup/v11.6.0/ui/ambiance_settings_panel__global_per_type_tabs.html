Maquette — onglet de bruitages :
Un seul composant « Réglages d'ambiance » (AmbianceSettingsPanel) porte tous les réglages de comportement son + lumière : il est rendu ici en mode global (page Ambiance) et, à l'identique, en mode surcharge dans l'éditeur de manche (maquette round_override). En mode global, les lignes de bruitages ajoutent les colonnes catalogue (fichier, durée, Remplacer / Restaurer / Tester) qui n'existent pas par manche : le fichier d'un son est un contenu du catalogue, pas un réglage. Le matériel (pont Hue, ampoules et rôles, périphérique audio, « Bruitages activés » lié au redémarrage) reste dans ses sections actuelles, hors du composant : il n'est jamais surchargeable.
#231 : les bruitages sont présentés en onglets — Global (7 cues v11.0) puis un onglet par type de jeu ne contenant que ses événements propres (8 nouvelles cues, chacune avec son fichier par défaut). Le décompte reste dans Global (sons longs).
