Maquette — état :
Onglet Son (composant SoundsManager, en-tête « Sortie audio » présenté en entier ; la table des sons est inchangée et résumée). La pastille d'en-tête ne change pas ; sous elle, une ligne de cause lisible (nouveau champ reason de GET /api/sound/status) et, quand l'interrupteur « Bruitages activés » a été modifié depuis le démarrage, une bannière « Redémarrage requis » (output = restart_required). Les mêmes informations sont écrites au démarrage dans le journal serveur (onglet Logs, fichier).

Bruitages désactivés dans config.json (sound.enabled = false, fichier lu depuis le répertoire de lancement : C:\BuzzControl\config.json). Activez l'interrupteur puis redémarrez.
