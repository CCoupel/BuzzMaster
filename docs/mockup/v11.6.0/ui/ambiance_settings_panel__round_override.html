Maquette — état :
Même composant AmbianceSettingsPanel qu'en page Ambiance, rendu en mode surcharge dans une fenêtre ouverte depuis l'en-tête de la manche (bouton « Ambiance », maquette admin_questions_list__round_ambiance_override). Chaque réglage a un état supplémentaire « Hérité » (défaut) qui affiche la valeur globale courante en italique ; choisir une valeur crée la surcharge, « Hérité » la retire. Les colonnes catalogue (fichier, Remplacer, Tester) n'apparaissent pas : une manche ne change pas les sons, seulement leur activation. Enregistrement : avec la structure des manches (ROUNDS_UPDATE), rien n'est persisté dans la configuration globale.
Précédence, champ par champ : global ← manche ← geste direct (popover d'en-tête). Un geste direct vaut jusqu'au prochain changement de manche ; il réécrit aussi la valeur globale seulement si la manche courante n'a pas de surcharge sur ce champ (comportement v11.4.0 conservé hors surcharge).
