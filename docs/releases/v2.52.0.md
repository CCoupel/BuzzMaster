# BuzzControl v2.52.0 - "Chronomètre Prédictif"

**Date de sortie** : 6 février 2026

## 🎉 Nouveautés

### ⏱️ Marqueurs d'indices sur le timer QCM

Le mode QCM devient encore plus stratégique avec l'ajout de marqueurs visuels sur la barre de temps ! Vous pouvez maintenant voir exactement quand les indices vont se déclencher.

**Avantage** : Les joueurs peuvent mieux gérer leur temps et leur prise de risque. Faut-il répondre maintenant ou attendre qu'une mauvaise réponse soit éliminée ? La tension monte !

**Comment ça marche ?**

1. **Repères visuels** : Des traits orange/jaune apparaissent sur la barre de progression du timer
2. **Positionnement intelligent** : Chaque trait indique le moment exact où un indice sera révélé (une mauvaise réponse invalidée)
3. **Animation de pulsation** : Quand le timer approche d'un seuil (15 secondes avant), le marqueur pulse pour attirer l'attention
4. **Animation de déclenchement** : Quand l'indice est révélé, le marqueur s'estompe élégamment

**Exemple d'utilisation** :
- Vous lancez une question QCM avec deux seuils d'indices : à 30 secondes et 15 secondes
- Sur l'affichage TV, les joueurs voient deux traits orange sur la barre de temps
- À 45 secondes du début, le premier trait commence à pulser
- À 30 secondes, une mauvaise réponse disparaît et le premier trait s'estompe
- Le second trait continue de pulser jusqu'à 15 secondes
- Les joueurs peuvent décider s'ils attendent le second indice ou tentent leur chance maintenant

### 🎯 Configuration flexible

Les marqueurs respectent vos règles de sécurité :
- **Seuil 1** : Minimum 2 secondes avant la fin
- **Seuil 2** : Minimum 1 seconde avant la fin
- **Écart minimum** : 1 seconde entre les deux seuils
- **Activation conditionnelle** : Les marqueurs n'apparaissent que si `QCM_HINTS_ENABLED = true` pour la question

**Avantage** : Vous gardez le contrôle total sur la difficulté de vos questions. Activez les indices et les marqueurs pour les questions difficiles, désactivez-les pour les questions faciles.

## 💡 Améliorations techniques

### 🎨 Interface utilisateur

- **`Timer.jsx`** : Nouveau prop `hintMarkers` pour afficher les marqueurs sur la barre de temps
- **`Timer.css`** : Styles `.hint-marker` avec animations `hint-marker-pulse` et `hint-marker-fade`
- **`PlayerDisplay.jsx`** : Calcul optimisé des positions des marqueurs via `useMemo`

### ⚙️ Performance

- Calcul des positions des marqueurs uniquement quand les seuils changent (évite les re-calculs inutiles)
- Animations CSS pures, pas de JavaScript pour les effets visuels
- Affichage conditionnel intelligent selon la configuration de la question

## 🚀 Comment utiliser cette fonctionnalité

### Activation

1. Allez dans **Questions** > **Modifier une question QCM**
2. Cochez **"Activer les indices"** (`QCM_HINTS_ENABLED`)
3. Définissez **Seuil 1** et **Seuil 2** (temps en secondes avant la fin)
4. Lancez la question en mode QCM

### Désactivation

Si vous ne voulez pas d'indices visuels sur certaines questions :
- Décochez **"Activer les indices"** pour cette question
- Les marqueurs disparaîtront automatiquement
