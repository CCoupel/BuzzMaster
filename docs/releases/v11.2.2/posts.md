## LinkedIn
BuzzControl v11.2.2 est disponible.

Les animateurs peuvent désormais choisir, carte par carte, comment une carte MEMOTION rapporte des points : étoiles, montant fixe, par unité… Le montant s'affiche clairement pour l'animateur avant et pendant le jeu.

Autre nouveauté pensée pour les soirées en direct : si le serveur perd son réseau, l'administration affiche une alerte plein écran, puis un bandeau, et confirme le retour du réseau.

Les sélecteurs de catégorie et de difficulté sont aussi harmonisés dans toute l'interface.

Détails dans les release notes.

## Reddit / Forum
**[Release] v11.2.2 - barème de points par carte MEMOTION et alerte « serveur sans réseau »**

Bonjour communauté,

**Ce qui change :**
- Barème par carte MEMOTION : étoiles ou montant fixe (SPEEDY, QCM) ; prorata, étoiles pleines, montant fixe ou par unité (MEMORY, RAFALE). Montant visible côté animateur et admin.
- Alerte plein écran sur l'admin quand le serveur n'a plus d'IPv4 utilisable (interfaces virtuelles ignorées), repliable en bandeau, toast au retour du réseau.
- Sélecteurs catégorie/difficulté unifiés ; cartes QCM MEMOTION sans indices.
- Corrections : message de refus d'enregistrement visible pour MEMORY/MEMOTION/RAFALE/ENTRACTE, rattachement du premier message WebSocket.
- Sous le capot : tests plus robustes, dépendances web à jour (Node 22 requis pour le build), CI Node 24.

**Feedback bienvenu** : issues GitHub du dépôt.
