# BuzzControl v3.1.2 - "Interface claire"

**Date de sortie** : 26 fevrier 2026

---

## Quoi de neuf ?

### Une seule modale pour toutes les operations USB

Avant cette version, configurer le WiFi d'un buzzer et flasher son firmware via USB etaient deux operations accessibles depuis des endroits differents de l'interface. C'est desormais reuni en un seul endroit : la modale USB unifiee.

**Benefice** : Vous branchez le buzzer, vous ouvrez la modale — et depuis la meme fenetre, vous pouvez soit configurer le reseau WiFi, soit flasher un nouveau firmware. Plus besoin de chercher ou se trouve le bon bouton.

**Comment l'utiliser :**

1. Branchez votre buzzer BuzzClick en USB
2. Cliquez sur le bouton USB dans l'interface (Config ou page Equipes)
3. La modale s'ouvre avec deux sections : **Config WiFi** et **Flash Firmware**
4. Selectionnez votre port USB une seule fois — il est partage entre les deux operations

---

### Badge "type de firmware" dans la page Config

La section Firmware de la page Config affiche desormais un badge indiquant le type du firmware de reference : **Full merged** (image complete, prete a flasher depuis le debut) ou **App only** (application seule, a utiliser uniquement via OTA).

**Benefice** : Vous savez immediatement si le firmware charge sur le serveur peut etre utilise pour un flash USB complet ou uniquement pour une mise a jour OTA. Plus de risque de tenter une operation impossible.

---

## Corrections

- Le bouton "Flash via USB" est maintenant grise automatiquement lorsque le firmware disponible est de type "App only". Cela evite de lancer un flash USB qui ne pourrait pas fonctionner.
- Le type de firmware (complet ou application seule) est desormais correctement transmis en temps reel via WebSocket. L'interface se met a jour sans rechargement de page.
- Le flash USB via esptool-js ecrit desormais depuis l'adresse correcte (0x0) pour un flash complet de la memoire flash. Un redemarrage automatique est declenche a la fin du flash, et une verification de version confirme que la mise a jour a bien ete appliquee.

## Comment mettre a jour

Telechargez la derniere version depuis la page des releases GitHub, remplacez l'executable serveur et relancez-le. Vos donnees (equipes, questions, scores) sont conservees.

Cette version ne contient pas de nouvelle version du firmware BuzzClick. Aucune mise a jour OTA des buzzers n'est necessaire apres ce patch serveur.
