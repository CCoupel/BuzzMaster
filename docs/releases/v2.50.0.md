# BuzzControl v2.50.0 - "Abeille Connectée"

**Date de sortie** : 1er février 2026

## 🎉 Nouveautés

### ⬆️ Mise à jour automatique du serveur

BuzzControl peut maintenant se mettre à jour tout seul, en un clic ! Fini les téléchargements manuels et les manipulations complexes.

**Avantage** : Vous êtes toujours à jour avec les dernières fonctionnalités et corrections, sans effort. Le système vérifie automatiquement les nouvelles versions et vous propose de les installer en toute sécurité.

**Comment ça marche ?**

1. **Notification automatique** : Un badge apparaît dans la barre de navigation quand une nouvelle version est disponible
2. **Page dédiée** : Accédez à `/admin/updates` pour voir toutes les versions disponibles
3. **Installation en un clic** : Téléchargement, backup automatique, et redémarrage - tout est géré pour vous
4. **Sécurité maximale** : Si quelque chose se passe mal, le système revient automatiquement à la version précédente

**Exemple d'utilisation** :
- Vous lancez BuzzControl pour votre soirée quiz
- Un badge vert "🔔" apparaît dans le menu : une nouvelle version est disponible
- Vous cliquez dessus et voyez les nouveautés de la v2.51.0
- Un clic sur "Installer" et hop, 2 minutes plus tard, vous avez la dernière version

### 📋 Interface de gestion des versions

La nouvelle page de mises à jour affiche :
- **Liste compacte** : Toutes les versions sur une seule ligne, facile à scanner
- **Icônes de statut** : ✅ version actuelle, ⬆️ plus récente disponible, ⚠️ version obsolète
- **Titres descriptifs** : Chaque version a un nom évocateur (ex: "Abeille Connectée")
- **Notes dépliables** : Consultez les changements en détail avec un beau rendu Markdown
- **Badge "Version locale"** : Pour les versions de développement non publiées

**Avantage** : Vous savez toujours où vous en êtes et ce qui a changé entre chaque version.

## 💡 Améliorations

### 🔧 Fonctionnalités techniques

- **Cache intelligent** : Les informations de mise à jour sont mises en cache 1 heure pour éviter de surcharger GitHub
- **Vérification de taille** : Le système refuse les téléchargements trop petits (< 40 MB) pour éviter les fichiers corrompus
- **Configuration flexible** : Vous pouvez désactiver la vérification automatique via `auto_check_updates` si vous préférez

### 🌐 API REST étendue

- Nouveaux endpoints pour gérer les mises à jour : `GET/POST /api/updates/*`
- Parseur Markdown intégré pour afficher joliment les notes de version

## 🚀 Comment mettre à jour

### Mise à jour automatique (recommandée)

1. Cliquez sur le badge de notification dans la barre de navigation
2. Sur la page Updates, cliquez sur "Installer" pour la version souhaitée
3. Attendez 2 minutes - le serveur se met à jour et redémarre automatiquement
4. Rafraîchissez votre navigateur - c'est prêt !

### Mise à jour manuelle (si nécessaire)

1. Téléchargez `buzzcontrol-windows-amd64.zip` depuis [GitHub Releases](https://github.com/cyril-repo/buzzcontrol/releases/tag/v2.50.0)
2. Arrêtez le serveur BuzzControl
3. Extrayez et remplacez `server.exe`
4. Relancez le serveur
