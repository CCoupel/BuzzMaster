# BuzzControl v3.7.0 - Edition Comete

**Date de release** : 27 avril 2026

---

## Ce qui change dans cette version

### Vos buzzers celebrent chaque point avec une animation lumineuse

Quand une equipe marque des points, les 23 LEDs de ses buzzers physiques s'illuminent d'une bande doree qui fait deux tours complets avant de revenir a la couleur de l'equipe. Pour les equipes a dominante jaune, la bande est blanche pour rester bien visible. Cette animation se declenche automatiquement a chaque attribution de points — qu'elle soit individuelle ou collective — et dure environ 3 secondes.

**Ce que ca apporte :**
- Une celebration visuelle et immediate a chaque bonne reponse
- Les joueurs voient et ressentent la recompense directement dans leur main
- Ambiance renforcee, surtout en soiree ou en salle avec les lumieres tamisees

---

### Les couleurs des buzzers collent enfin parfaitement aux couleurs de vos equipes

L'affichage LED sur les buzzers physiques utilisait jusqu'a present un calcul de correspondance qui pouvait produire des resultats visuellement faux — un rouge trop orangé, un violet trop rose. La v3.7.0 corrige cela en calculant la teinte par approche HSL, le meme modele que celui utilise par l'oeil humain pour percevoir les couleurs. Resultat : ce que vous voyez dans l'interface admin correspond maintenant fidellement a ce qui s'allume sur le buzzer.

**Ce que ca apporte :**
- Coherence parfaite entre l'interface web et les buzzers physiques
- Identification des equipes plus rapide et plus intuitive pendant le jeu

---

### Double QR code a l'ecran TV lors de l'inscription des joueurs

La phase d'inscription des joueurs affiche desormais deux QR codes cote a cote sur l'ecran TV (ou videoprojecteur) :
- **QR code WiFi** : scanne-le pour rejoindre directement le bon reseau sans chercher le nom dans les reglages
- **QR code VJoueur** : scanne-le pour ouvrir la page d'inscription immediatement

Une barre de progression indique en temps reel le nombre de joueurs inscrits par rapport au maximum prevu. Plus besoin de se demander si tout le monde est connecte avant de lancer la partie.

**Ce que ca apporte :**
- Demarrage de partie plus rapide, meme avec un groupe non experimente
- Moins d'allers-retours entre le presentateur et les participants
- Lisibilite optimisee pour une projection grande distance

---

### Filtrage des questions par categorie directement pendant la partie

Sur la page de jeu, la barre qui affiche l'equilibre des categories de questions permet maintenant de cliquer sur une ou plusieurs categories pour filtrer la liste des questions visibles. Combinez plusieurs categories pour affiner votre selection. Sur la page Questions, le meme systeme de filtres multi-selection est disponible pour gerer votre banque de questions.

**Ce que ca apporte :**
- Naviguez directement vers les questions du theme en cours
- Utile pour animer des soirees a theme ou des sessions par domaine de connaissances
- Gestion de grande banque de questions simplifiee

---

### Le numero de version dans la barre de navigation est maintenant cliquable

Le numero de version affiche en haut de l'interface admin est desormais un lien direct vers la page des mises a jour. Un clic suffit pour verifier si une nouvelle version est disponible, depuis n'importe quelle page de l'application.

---

### Noms de fichiers de sauvegarde avec date et version

Les archives de sauvegarde telechargees depuis l'interface incluent desormais la version du serveur et la date dans leur nom :

- `buzzcontrol-full-backup-v3.7.0_2026-04-27.tar`
- `buzzcontrol-backup-v3.7.0_2026-04-27.tar`

Plus besoin de noter manuellement quand une sauvegarde a ete creee — l'information est directement dans le nom du fichier.

---

## Corrections techniques

- **Mises a jour firmware OTA fiabilisees** : le telechargement du firmware sur les buzzers physiques pouvait echouer silencieusement vers 20% de la progression. Ce bug est corrige — la mise a jour OTA se deroule maintenant sans interruption, meme sur les connexions WiFi fragiles.
- **Pile d'execution websocket elargie** : des crashes aleatoires pouvaient survenir lors de la reception de longs messages. La taille de la pile reservee a la tache WebSocket du buzzer a ete doublée pour eliminer ces incidents.
- **Numero de version firmware corrige** : le firmware etait compile avec le mauvais numero de version — le badge affiché dans l'interface admin est maintenant correct apres flash.

---

## Comment mettre a jour

1. Telechargez le fichier correspondant a votre plateforme ci-dessous
2. Remplacez votre executable actuel par le nouveau
3. Relancez BuzzControl — vos donnees, questions et scores sont preserves

Pour mettre a jour le firmware de vos buzzers physiques apres avoir lance le nouveau serveur : allez dans la page **Config**, section **Firmware BuzzClick**, puis cliquez sur **Mettre a jour tout**.
