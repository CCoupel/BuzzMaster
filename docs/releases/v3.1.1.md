# BuzzControl v3.1.1 - "Mise a jour sereine"

**Date de sortie** : 22 fevrier 2026

---

## Quoi de neuf ?

### Retour au firmware officiel en un clic

Vous avez teste un firmware experimental sur vos buzzers et vous souhaitez revenir a la version stable ? Un nouveau bouton "Restaurer firmware embarque" apparait dans la page Config lorsqu'un firmware officiel est disponible dans le serveur.

**Benefice** : Plus besoin de retrouver manuellement le bon fichier .bin. Le serveur sait quelle version est la sienne et peut remettre vos buzzers dans un etat connu en quelques secondes.

**Comment l'utiliser :**

1. Allez dans la page **Config**
2. Dans la section "Gestion Firmware", le bouton apparait automatiquement si un firmware officiel est embarque dans votre version du serveur
3. Cliquez sur "Restaurer firmware embarque"
4. Lancez ensuite la mise a jour OTA sur vos buzzers comme d'habitude

---

### Barres de progression OTA plus fiables

Les barres de progression pendant une mise a jour firmware restent desormais orange jusqu'a ce que le buzzer ait effectivement redemarrage avec son nouveau firmware.

**Avant** : La barre pouvait passer au vert des la fin du telechargement, avant que le buzzer soit reellement operationnel avec sa nouvelle version.

**Apres** : La barre repasse au vert uniquement quand le buzzer se reconnecte et annonce sa nouvelle version. Vous savez avec certitude que la mise a jour est terminee.

---

### Badge firmware cliquable dans la page Joueurs

Dans la page Joueurs (Teams), le badge indiquant la version firmware d'un buzzer est maintenant cliquable. Un clic ouvre directement la fenetree de mise a jour pour ce buzzer.

**Benefice** : Vous n'avez plus besoin de passer par la page Config pour mettre a jour un buzzer individuel. Depuis la page de jeu, vous pouvez lancer une mise a jour en deux clics.

---

### "Tout mettre a jour" avec retour visuel

Le bouton "Tout mettre a jour" de la page Config ouvre desormais la meme modale avec barres de progression que lors d'une mise a jour individuelle.

**Benefice** : Vous visualisez l'avancement de chaque buzzer en temps reel, sans incertitude sur ce qui se passe.

---

## Corrections

- Les buzzers construisent desormais leur URL de mise a jour a partir de la configuration reseau stockee sur l'appareil. Cela corrige les cas ou un buzzer ne parvenait pas a telecharger le nouveau firmware en raison d'une adresse serveur codee en dur.

## Comment mettre a jour

Telechargez la derniere version depuis la page des releases GitHub, remplacez l'executable serveur et relancez-le. Vos donnees (equipes, questions, scores) sont conservees.

Si vous souhaitez egalement mettre a jour le firmware de vos buzzers BuzzClick, rendez-vous dans Config > Gestion Firmware apres le redemarrage du serveur.
