#114 — fix(tv): lisibilité du texte du type de question (phase READY)

Précision de phase (rapport code-reviewer-issues-v652-20260820-111252.md) : le texte du type de question (SPEEDY/ARDOISE/QCM/MEMOTION) n'apparaît pas en phase PREPARE (écran générique "NOUVELLE QUESTION") mais en phase READY, via ReadyCategoryDisplay / classe .ready-game-type (PlayerDisplay.jsx:41-46, 83-91). Actuellement : couleur + glow de même teinte seulement (ex. QCM #34d399 sur glow rgba(52,211,153,0.6)) — aucun contour contrastant, aucun assombrissement de box.
