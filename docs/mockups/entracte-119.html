Mode ENTRACTE — 4 surfaces

Maquette statique AVANT/APRÈS de validation (milestone v6.5.2, issue #119 redéfinie). #119 n'est plus un type de question — c'est un mode de pause globale déclenché depuis l'admin, qui affiche un panneau configurable (texte + fond image) par-dessus l'écran TV et VJoueur, avec le reste de l'interface visible en fond mais estompé (filtre CSS). Aucun code applicatif n'a été modifié pour produire cette maquette.

Recette de filtre partagée — même traitement visuel sur les 4 surfaces, pour une cohérence de perception "pause" quel que soit l'écran regardé :
filter: grayscale(0.85) brightness(0.55);
Suffisamment marqué pour signaler clairement l'arrêt du jeu, sans rendre le contenu totalement illisible (on doit pouvoir deviner qu'une partie était en cours).
