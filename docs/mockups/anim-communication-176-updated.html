Points techniques

Guard-fou : Pas de résurrection du message

La régie tape « Salut » → pause d'envoi → « Vu » animateur → blur accidentel. Sans protection, le blur renverrait « Salut » et ressusciterait le message. Deux gardiens empêchent ça :

  • Serveur : REGIE_MESSAGE_SEND idempotent — texte identique = no-op
  • Client : Ne vide le champ que si son contenu encore égal au message effacé
CSS obligatoire pour le double-tap

touch-action: manipulation sur la zone active (AnimPage) — sans ça, le double-tap déclenche le zoom navigateur et devient inutilisable sur tablette.

Timers à nettoyer
  • Debounce d'envoi (2000 ms) → cleanup à démontage
  • Indicateur « Vu par l'animateur » (~4 s) → cleanup à démontage
  • Hook useDoubleTap → cleanup à démontage
