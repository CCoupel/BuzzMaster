# BuzzControl v3.3.0 - Edition Identifiee

**Date de release** : 28 mars 2026

---

## Ce qui change dans cette version

### Un executable Windows mieux integre

Le fichier `buzzcontrol.exe` embarque desormais des metadonnees officielles visibles directement dans Windows.

Faites un clic droit sur l'executable, allez dans **Proprietes > Details** : vous y trouverez le nom du produit, le numero de version, la description et le copyright — comme tout logiciel professionnel.

**Ce que ca apporte :**
- Identification claire du fichier dans l'explorateur Windows
- Plus simple a reconnaitre parmi d'autres executables
- L'icone abeille est integree au binaire pour une meilleure presentation dans Windows

**Exemple :**

Si vous avez plusieurs versions de BuzzControl sur votre machine, les metadonnees vous permettent d'identifier instantanement laquelle est laquelle sans avoir a lancer le programme.

---

## Correctifs et ameliorations

Aucun changement fonctionnel dans cette version. Le systeme de jeu, les buzzers, les modes QCM et Memory, et toutes les fonctionnalites existantes restent identiques.

---

## Comment mettre a jour

1. Telechargez `buzzcontrol-v3.3.0-windows-amd64.exe` depuis la [release GitHub](https://github.com/CCoupel/BuzzMaster/releases/tag/v3.3.0)
2. Remplacez votre ancien executable par le nouveau
3. Relancez BuzzControl — aucune autre manipulation n'est necessaire

La mise a jour est optionnelle pour les utilisateurs satisfaits de leur version actuelle. Aucune donnee n'est affectee.
