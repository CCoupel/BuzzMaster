## Design Decisions

1. **Dedicated endpoints over generic broadcast** — reduces client payload, clearer semantics, enables progressive rollout
2. **MSG_ID omitempty** — maintains backward compatibility with v3.7.x firmwares
3. **ACK before apply** — firmware sends ACK prior to action execution to minimize latency
4. **AckManager registre** — centralized timeout/retry/expiry logic vs per-message tracking
5. **Badge styling inline React** — consistent with v3.6.8 CONNECTED badge pattern
