## Prérequis

- [ ] QUALIF, `/admin` (page de jeu), `/tv`, `/anim` (tablette animateur), un second onglet `/admin`

- [ ] Quiz avec : 1 **QCM** (4 réponses, indices activés pour l'un), 1 **ARDOISE**, 1 **SPEEDY**, 1 **MEMORY** multi-équipes, 1 **RAFALE** (si disponible)

## Scénario 2 — QCM : clic sur les réponses

| Étape | Action | Résultat attendu | Résultat obtenu | OK ? |
|-------|--------|------------------|-----------------|------|
| 1 | Chaque bouton de réponse | Affiche « N équipe(s) » qui l'ont donnée ; la bonne réponse est marquée « ✓ » | | |
| 2 | Cliquer la **bonne** réponse | Les équipes qui l'ont donnée sont cochées (aperçu « +N » sur chaque carte) ; montant = points de la question ; bouton « Donner les points (N) » | | |
| 3 | Cliquer une **mauvaise** réponse | Tout est décoché, puis les équipes de cette réponse sont cochées ; montant **−1** ; bouton rouge **« Retirer les points (N) »** | | |
| 4 | Modifier le montant (−, +, saisie) | Le montant s'applique à toutes les équipes cochées ; aperçu mis à jour ; le libellé passe de « Retirer » à « Donner » au-dessus de 0 | | |
| 5 | Question QCM avec **indices** : cliquer la bonne réponse | L'aperçu diffère d'une équipe à l'autre (pénalité d'indices) ; si le montant est modifié à la main, il devient **uniforme** | | |

## Scénario 7 — Non-régression

- [ ] Clic sur la carte d'équipe (crédit unitaire), boutons ± de la page Scores, crédit depuis l'anim : comme avant
- [ ] Historique : une ligne « points attribués » par équipe créditée par lot
- [ ] La page Palmarès / TV affiche les scores à jour

## Critères de validation

- [ ] Ni cases ni barre avant le REVEAL ; clic QCM conforme à la maquette
- [ ] Un lot ne crédite jamais deux fois une équipe pour la même question
- [ ] Une erreur de validation n'applique rien ; le résultat revient toujours à l'émetteur
- [ ] Effets publics groupés (un son, une comète par équipe, un flash)
- [ ] L'admin voit les équipes déjà créditées (y compris depuis l'anim)
