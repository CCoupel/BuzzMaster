## Scénario 1 — POST /api/categories avec image (multipart) (#100)

**Objectif** : Vérifier que la création de catégorie nécessite une image et que l'image est stockée et servie.

### 1a — Formulaire inline dans QuestionsPage

| Étape | Action | Résultat Attendu | Résultat Obtenu | OK ? |
|-------|--------|-----------------|----------------|------|
| 1 | Naviguer vers `/questions` | Page chargée | | |
| 2 | Cliquer sur "+" dans le sélecteur de catégories | Formulaire inline affiché avec : champ texte, bouton `📁 Choisir une image…`, boutons Valider/Annuler | | |
| 3 | Saisir "Ma Catégorie" et cliquer "Valider" **sans choisir d'image** | Message d'erreur **"Image requise"** s'affiche, pas d'appel réseau | | |
| 4 | Cliquer `📁 Choisir une image…` et sélectionner un fichier `.png` | Le label affiche `✓ <nom-du-fichier>` | | |
| 5 | Cliquer "Valider" | Formulaire fermé, nouvelle catégorie auto-sélectionnée dans le sélecteur | | |
| 6 | Vérifier via `curl -s http://localhost/api/categories` | La catégorie apparaît avec `imageURL` **non-vide** (ex: `"/files/categories/MA_CATEGORIE.png"`) | | |
| 7 | Accéder à l'URL de l'image dans le navigateur | Image servie correctement | | |

### 1b — Cas limites fichier

| Étape | Action | Résultat Attendu | Résultat Obtenu | OK ? |
|-------|--------|-----------------|----------------|------|
| 8 | Tenter de sélectionner un fichier `.pdf` ou `.txt` | Le file picker le refuse (filtre accept) | | |
| 9 | Tenter POST via curl avec extension invalide | `curl -s -X POST http://localhost/api/categories -F "name=Test" -F "file=@doc.pdf;type=application/pdf"` → 400 | | |

### 1c — API directe (smoke)

```bash
# Créer une catégorie avec image PNG
curl -s -X POST http://localhost/api/categories \
  -F "name=Sport Extreme" \
  -F "file=@/tmp/test.png;type=image/png" | python3 -m json.tool
# Attendu : {"key":"SPORT_EXTREME","name":"Sport Extreme","imageURL":"/files/categories/SPORT_EXTREME.png","isCustom":true}

# Conflit → 409
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost/api/categories \
  -F "name=Sport Extreme" \
  -F "file=@/tmp/test.png;type=image/png"
# Attendu : 409

# Fichier manquant → 400
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost/api/categories \
  -F "name=Autre Test"
# Attendu : 400

# Extension invalide → 400
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost/api/categories \
  -F "name=Autre Test" \
  -F "file=@/tmp/doc.pdf;type=application/pdf"
# Attendu : 400
```
