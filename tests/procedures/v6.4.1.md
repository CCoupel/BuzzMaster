## Scénario 1 — Stabilité du serveur sous jeu prolongé (#151, non-régression fonctionnelle)

**Objectif** : Vérifier que le durcissement anti-panique des 5 goroutines (countdown, timer de jeu, MEMOTION carte, MEMOTION mémorisation, auto-flip-back MEMORY) n'a introduit **aucune régression observable** sur le déroulement normal d'une partie. Ce scénario ne peut pas déclencher une vraie panique (réservé aux tests automatisés) — il vérifie que le comportement nominal des 5 timers reste identique après le refactor du verrou.

| Étape | Action | Résultat Attendu | Résultat Obtenu | OK ? |
|-------|--------|-----------------|----------------|------|
| 1 | Démarrer une partie QCM, laisser le countdown 3-2-1 s'écouler entièrement | Countdown décompte normalement jusqu'à 0, partie démarre automatiquement | | |

| 3 | Laisser le timer expirer complètement (sans buzz) | Le round s'arrête automatiquement (`Stop()`), écran passe à l'état attendu | | |
| 4 | Démarrer une partie MEMOTION (mode carte, sans mode secret) | Timer carte décompte normalement, TV affiche le temps restant | | |
| 5 | Laisser le timer carte expirer | Timer s'arrête, phase reste STARTED, admin doit agir manuellement (comportement inchangé) | | |

| 10 | Consulter les logs serveur après toute la session | **Aucune ligne `recovered panic`** ne doit apparaître (comportement nominal, pas de panique déclenchée) | | |
